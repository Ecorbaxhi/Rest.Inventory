Efficient inventory management is critical for restaurant operations, yet many small establishments continue to rely on manual, paper-based workflows that are time-consuming and error-prone. This project presents Rest.Inventory, a web-based inventory management system developed for a small independent restaurant, Fiorentini, in Rutherford, NJ, designed to replace handwritten inventory lists with a secure, structured, and role-based digital solution.The system is implemented using a modern backend architecture built with FastAPI, exposing RESTful API endpoints secured through JWT authentication and role-based access control. Different user roles, including staff and restaurant owners, can create and manage inventory submissions through standardized workflows. Product data is centrally managed through a structured catalog, enabling consistency, traceability, and future reporting capabilities.An integrated AI component enhances decision support by automatically generating summaries and insights for inventory submissions using a large language model (Google Gemini). In addition, the system produces automated weekly AI inventory reports that highlight trends, dominant categories, and potential alerts, available both as API responses and downloadable files. The application is fully deployed to a cloud environment, demonstrating real-world usability beyond local development tools. There are no costs for this application, or almost none.Overall, Rest.Inventory transforms a manual inventory process into a scalable, cloud-ready, and AI-assisted platform, improving operational efficiency while establishing a foundation for future analytics and intelligent automation.
